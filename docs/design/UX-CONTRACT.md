# 凌点 AI UX Contract

这份契约约束点数、会员、个人中心和后台管理功能的跨页面行为。它服务于当前 MVP，不包含安全策略重构。

## Canonical UI Map

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
|---|---|---|---|---|
| Table Selection | 页面表格自身的批量选择实现 | 本页业务流程 | page / all-results | 类型检查与页面回归 |
| Select/Listbox | 原生 `select` 控件 | 本文件与 `premium-ui.json` | native | 键盘操作与页面回归 |
| Date | 原生日期输入控件 | 本文件与 `premium-ui.json` | native | 本地化显示与页面回归 |
| Form | 页面表单的手动校验状态 | 本文件 | create / edit | 类型检查与提交失败回归 |
| Scrollbar | 全局应用样式 | `Aiplatform-web/src/styles/index.css` | geometry exceptions | 生产构建与视觉检查 |
| Toast | 现有应用通知状态 | `Aiplatform-web/src/stores/appStore.ts` | success / warning / info / error | 类型检查与页面回归 |
| CRUD | 现有页面 API 与服务端权限 | `Aiplatform-web/src/services/api.ts` | return / stay | 类型检查与接口回归 |

本项目选择原生下拉和日期控件，以保留系统键盘、日期选择器和中文环境行为；表单关闭浏览器默认气泡，由页面状态负责提示。

## 管理控制台导航

- 管理后台是独立的运营工作区，不使用扁平的全局按钮堆叠；桌面端按监控、用户与商业、运营、治理与运维分组展示侧栏导航，窄屏使用同一组模块的横向导航。
- 每个模块保留当前模块标题、用途描述和数据范围；模块切换使用导航语义和 `aria-current`，不把可独立理解的后台模块伪装成无层级的装饰性标签。
- 后台总览的系统健康状态允许处于检测中；只有服务端健康检查返回全部正常时才显示平台运行正常。

## Language and formatting

- 中文（`zh-CN`）是默认界面语言，已有国际化入口继续保留。
- 时间沿用前端现有本地化格式；点数显示至少保留两位小数，金额和流水号保持可复制。
- 状态文案使用用户能理解的业务词：消耗、充值赠送、过期、退款、续费、升级、封禁、解封。

## Records and pagination

- 个人中心概览展示今日消耗、本月消耗、累计消耗、剩余点数和近 30 日调用趋势。
- 点数流水、充值/赠送记录和会员历史都使用服务端分页；列表响应必须同时带 `records`/`total` 或分页对象。
- 点数流水支持全部、消耗、收入、过期、退款分类；筛选和页码变化后显示加载、空数据或失败重试状态。
- 管理员操作日志使用服务端分页，并支持管理员、操作类型和日期范围筛选。

## Mutations

- 点数调整、会员变更、密码重置、封禁/解封均为请求成功后更新 UI；提交中禁止重复提交。
- 封禁/解封先通过 `ConfirmDialog` 确认；点数、会员、密码使用应用内业务弹窗。
- 会员续费延长当前有效期；升级切换到更高等级；低于当前等级的套餐不可购买。
- 任何失败都必须保留当前数据并显示可理解的错误提示，不能静默吞掉。

## Permission and ownership

- 后台业务接口继续由后端管理员权限控制，前端只负责展示可用操作和结果。
- 用户封禁后，登录、聊天和 API Key 访问都应被后端状态判断拦截；前端不以隐藏按钮代替权限控制。
- 安全配置页面和更广泛的安全审计不在本次契约范围内。

## Visual consistency

- 使用 `DESIGN.md` 中的现有主题变量、边框、圆角和状态色。
- 表格操作列保持“查看/业务操作/状态操作”的顺序，危险操作使用危险色并明确动词。
- 概览卡片只放摘要，完整记录进入分页列表，避免把大量历史数据塞进统计卡片。
