# 部署与环境说明

本目录用于记录可复用的部署约定。生产环境的主机地址、SSH 私钥、数据库密码、OAuth 密钥和邮件凭据必须由部署者通过受控环境提供，不应写进仓库文件或命令历史。

## 建议流程

1. 从受信任的代码版本构建后端和前端产物。
2. 在目标机部署前，检查当前服务容器、环境变量和磁盘空间，并准备可恢复的备份。
3. 先核对数据库迁移脚本，按版本顺序执行；不要用 `rebuild.sql` 覆盖已有数据。
4. 按项目当前部署脚本完成变更，并检查健康接口、前端资源和关键业务路径。
5. 保留上一个可恢复版本与迁移记录；若验收失败，按发布批次回滚。

根目录的 `DEPLOY-NO-DOCKER.md` 是旧文档入口，仅保留到本说明的链接。具体发布脚本可能面向特定环境，执行前应阅读脚本并通过环境变量显式指定目标。
