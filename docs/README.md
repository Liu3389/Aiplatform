# 文档索引

这里按用途归档平台文档。涉及某个模块实现时，应同时核对源码与当前配置；调研和历史记录不代表功能已上线或已验收。

| 目录 | 内容 | 状态标记 |
| --- | --- | --- |
| [`design/`](design/) | 跨页面视觉与交互约定 | `规范` |
| [`deployment/`](deployment/) | 环境准备、数据库迁移和发布注意事项 | `操作说明` |
| [`integrations/`](integrations/) | 第三方平台接入配置 | `集成说明` |
| [`research/`](research/) | 外部项目与产品方向调研 | `调研，非实现承诺` |
| `operations/internal/` | 本机整改记录与运行状态 | `本地资料，不提交` |

## 维护约定

- 面向所有仓库使用者的说明放在 `README.md` 或对应公共文档目录。
- 本机路径、服务器状态、临时发布记录和运行凭据不进入公开文档；本机记录使用 `.local.md` 后缀并由 `.gitignore` 排除。
- 设计预览与临时验收产物保留在本地 `design-previews/`，正式产品资源放在前端的 `public/` 目录。
- 文档引用使用相对路径；移动文档时同步更新引用。
